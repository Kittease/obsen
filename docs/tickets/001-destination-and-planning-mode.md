## Question

Is the destination of this effort a validated spec (planning), or a working plugin (execution carried into the map)?

## Resolution

**A complete, validated spec for Obsen v1, plus implementation-ready tickets.** Implementation is a separate follow-on effort once the way is clear.

The broader journey is: find the way (this map) → spec and ticket it → implement it. The spec must therefore include everything an implementing agent needs to work with confidence — including the testing strategy (see [013](013-testability-architecture.md) and the test-harness research ticket).
